# Prompt: LinkPulse logo

## Prompt
Flat vector logo emblem for "LinkPulse", a European professional text-first
social platform in 2077. Distinct mark derived from its name roots "link"
(hypertext) and "pulse" (heartbeat of thought) — an interlinked chain-link node
fused with a clean pulse/heartbeat waveform, evoking the "ThoughtPulse" feature
and the curated, intellectual, analytics-driven values. Deep-blue base with a
single contrasting accent, monochrome-to-two-color palette fitting the calm
European-intellectual brand. Clean geometric shape, minimal, scalable, centered
on transparent background, transparent PNG, 8k. Graphic novel / editorial
flat-vector style consistent with the project.

## Negative Prompt
--no photorealistic photo, 3D render, text inside emblem, literal letters
replacing the mark, gradients, drop shadows, crowded detail, anime, cartoon,
watermark
