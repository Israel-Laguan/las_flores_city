# Prompt: VoxStream logo

**Tool:** MidJourney --v 6 --ar 1:1 --style raw

## Prompt
Flat vector logo emblem for "VoxStream", a European/American professional
streaming platform in 2077. Distinct mark derived from its name roots "Vox"
(Lat. voice) and "Stream" — refined voice/sound waveform bars crossed by a
streaming signal arc, evoking high-quality streams, curated playlists, paywalled
expert commentary, and substance-over-gamification values. Deep-navy base with a
silver/cyan accent, monochrome-to-two-color palette fitting the serious,
professional brand. Clean geometric shape, minimal, scalable, centered on
transparent background, transparent PNG, 8k. Graphic novel / editorial
flat-vector style consistent with the project.

## Negative Prompt
--no photorealistic photo, 3D render, text inside emblem, literal letters
replacing the mark, gradients, drop shadows, crowded detail, anime, cartoon,
watermark
