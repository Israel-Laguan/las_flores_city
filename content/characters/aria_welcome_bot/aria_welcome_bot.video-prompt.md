# Video Prompts: ARIA

NOTE: aria_welcome_bot__default.png (the YAML portrait) shows a pale, short-haired avatar in front of a dark grey gradient; it has no cheek seam and no glowing eyes or halo motif. A second file, aria__default.png, shows a different male-presenting design with earbuds, a logo and a glowing circuit backdrop and contradicts the no-earbud rule; do not use it as reference.

Generate seamless looping portrait videos from each expression variant PNG. Use the corresponding `aria_welcome_bot__<expression>.png` as the input image for each prompt. The avatar on the reference image is the character described in the source prompt file.
