# M4 — Media Platform Logo Prompts (5)

**Milestone file:** `1786049707544-m4-media-logos.md`
**Depends on:** M1. Independent of M2/M3.
**Deliverable:** a `<slug>.prompt.md` (logo type) for each of the 5 social-media
platforms in `content/lore/media/platforms/`.
**Status:** executable. Run as its own chat; read master + M1 docs first.

---

## Goal

Add a `.prompt.md` + `assets/` dir for each social-media platform so each can be
illustrated with a **logo** (and optionally a mascot/interface banner). Today
each platform folder has only `<slug>.md`. Reference model:
`content/lore/media/social_media_ecosystem/` (has prompt + asset) and the press
outlets.

## Scope (5)

`linkpulse`, `playnetix`, `shenshou`, `vitrina`, `voxstream`
(→ `content/lore/media/platforms/<slug>/`)

## Per-platform steps

1. Read `content/lore/media/platforms/<slug>/<slug>.md` (brand identity).
2. Create `content/lore/media/platforms/<slug>/<slug>.prompt.md` with this
   **logo template**:

```markdown
---
name: <Platform Name>
type: logo
size: 1024x1024
aspect_ratio: 1:1
source: content/lore/media/platforms/<slug>/<slug>.md
target: `assets/<slug>__default.png`
consumer: logo
---

# Prompt: <Platform Name> logo

## Prompt
<Flat vector logo emblem for "<Platform Name>", a <region/type> social platform
in 2077. Distinct mark derived from <brand identity from .md: name root, motif,
values>. Monochrome-to-two-color palette fitting the brand. Clean geometric
shape, minimal, scalable, centered on transparent background, transparent PNG,
8k. Graphic novel / editorial flat-vector style consistent with the project.>

## Negative Prompt
--no <photorealistic photo, 3D render, text inside emblem, literal letters
replacing the mark, gradients, drop shadows, gradients, crowded detail, anime,
cartoon, watermark>

## Variations
- [ ] Logo on a dark UI card (app icon treatment)
- [ ] Logo lockup with the platform wordmark below
- [ ] Monochrome single-color version
```

   (Adapt wording from the brand `.md`; the project's graphic-novel/editorial
   style still applies — no photorealistic, no anime.)
3. Create the `assets/` folder (empty for now — PNGs generated in the deferred
   asset pass). Run `bash scripts/backup-content-assets.sh` first if you will
   place any file in it (recommended: mirror the press-outlet layout).

## Acceptance criteria (M4)

- [ ] Each of the 5 platforms has a `<slug>.prompt.md` matching the logo template.
- [ ] Brand identity in each prompt is grounded in its `<slug>.md` (no generic
      copy-paste across platforms).
- [ ] Prompts use the project graphic-novel/editorial vector style (no photorealistic).
- [ ] Each has an `assets/` folder.
