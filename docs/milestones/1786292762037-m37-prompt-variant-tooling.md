# M37 — Prompt-Variant Tooling Reconciliation

**Milestone file:** `M37-prompt-variant-tooling.md`
**Depends on:** `1786049707544-m1-template-and-strategy.md` (PROMPT_AUTHORING_SPEC.md),
M28 (prompt-length linter).
**Source plans:** `.mimocode/plans/1784733929231-hidden-garden.md` (variants system),
`1784749938291-diffident-jellyfish.md` + `1784755191854-crisp-wolf.md` (batch milestone cleanup)
**Status:** executable. The two-stage `**Edit prompt:**` design was superseded; tooling still

---

## Goal

Align the asset-pipeline prompt tooling with the canonical `## Variations` + `## Expression
Variants` spec (`docs/PROMPT_AUTHORING_SPEC.md:155-156,264-266`) and the Expression Variants model
(`docs/ASSET_EXPRESSION_VOCABULARY.md`), and retire the now-dead two-stage variant scripts.

## Current state (verified 2026-08-09)

- The canonical spec mandates `## Variations` + `## Expression Variants` and the `portrait_urls[]`
  / `background_urls[]` `expression`-tag model. The legacy hidden-garden design used a different
  two-stage `## Variants (image-to-image)` + `**Edit prompt:**` + `asset_paths.portrait_base_url`.
- **Where the two-stage format actually lives today:** exactly **20 files, all `content/scenes/*`**
  (45 occurrences), e.g. `content/scenes/cafe/cafe.prompt.md:23-33`. 0 character files, 0 district
  files. `grep '\*\*Edit prompt:\*\*' content` = 20.
- `shared/src/schemas/yaml-content.ts:53-60` defines `asset_paths` as a **closed** object
  (`portrait`, `biometric`, `expression_strip`, `face_base`, `hair_front`, `hair_back`) — there is
  **no** `portrait_base_url`, and `grep portrait_base_url content` = 0. The hidden-garden schema
  premise ("asset_paths is open-ended") is **false today**.
- `scripts/generate-variants.sh` exists (274 lines) but is **practically dead**: it skips every
  entity lacking `portrait_base_url` (`:192-195`) = 100% of entities, and the i2i step is
  hard-deadlocked per `docs/VARIANT_GENERATION_RUNBOOK.md:10-46` (NIM rejects URL/base64; akool
  cannot reach local MinIO). No YAML write-back, no `.generation-log.json` metadata.
- `scripts/migrate-variations-to-variants.mjs` exists but its effect was reverted (191 character +
  73 location files are back on `## Variations`).
- `scripts/asset-pipeline/scripts/generate-prompt.mjs:91-102,133-144` still emits the
  **old** `## Variants (image-to-image)` stubs — these contradict the canonical spec, so freshly
  generated files fail the audit checklist.
- `scripts/asset-pipeline/scripts/check-prompt-lengths.mjs:8-11` still validates the old
  `### \`night\` — <name>` + `**Edit prompt:**` i2i block format. Not wired into any npm script.
- The 7 `variant-prompts-batch-*.md` milestone files are **gone** — including Batch 7, which
  `diffident-jellyfish` / `crisp-wolf` explicitly said to keep. Only these plan files record that
  Batch 7 (locations) was planned.

## Steps

### 1. Fix the prompt generator
- Update `generate-prompt.mjs` stubs (`:91-102,133-144`) to emit the canonical `## Variations` +
  `## Expression Variants` (characters) / environment variants (locations) shape from
  `PROMPT_AUTHORING_SPEC.md`, not `## Variants (image-to-image)`.

### 2. Retire dead two-stage tooling
- Delete `scripts/generate-variants.sh` (dead: requires non-existent `portrait_base_url`; i2i
  deadlock). If any value remains (e.g. `parseVariants`), fold it into
  `scripts/asset-pipeline/scripts/generate-prompt.mjs` (the `parseVariants()` there at `:638-672`
  is still referenced by nothing wired — confirm before keeping).
- Delete `scripts/migrate-variations-to-variants.mjs` (effect reverted; would re-introduce drift).
- Update `docs/VARIANT_GENERATION_RUNBOOK.md` to state the two-stage i2i path is retired and
  variants are authored by hand under the canonical spec.

### 3. Re-point the linter
- Update `check-prompt-lengths.mjs:8-11` to validate the canonical variant block shape (or drop the
  variant-format assertion if `npm run validate:content` already covers structure). Keep the
  800/2000 length checks (those feed M28).

## Acceptance criteria

- [ ] New prompts generated by `generate-prompt.mjs` follow the canonical `## Variations` +
      `## Expression Variants` / environment-variant shape.
- [ ] `scripts/generate-variants.sh` and `scripts/migrate-variations-to-variants.mjs` removed.
- [ ] `docs/VARIANT_GENERATION_RUNBOOK.md` reflects the retired two-stage path.
- [ ] `check-prompt-lengths.mjs` no longer enforces the dead `**Edit prompt:**` format.
